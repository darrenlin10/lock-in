Pick a single deadline that matters. Lock-In keeps its exact date on the lock screen and counts remaining calendar days in the timezone you choose.

Deadline type
How the countdown is calculated
  • Date-only: remaining calendar days in the chosen timezone. Shows “Due today” on the date and “Overdue” after it.
  • Specific time: stores the exact instant. Before it, shows calendar days left (or “Due today”). When the instant passes, shows “Overdue”.
  • Days are counted from calendar dates, not by dividing seconds by 86,400, so daylight-saving changes never shift the count.
  • A wallpaper is a snapshot, not a running timer. Every image carries an “As of” date and the exact due date.

    How to set it

    iPhone
    1. Tap Share / Save to Photos (or download, then save the image to Photos).
    2. Settings → Wallpaper → Add New Wallpaper → Photos, and pick the image. Or long-press the lock screen and tap “+”.
    3. Keep the image unzoomed so the paper stays where you placed it. Choose “Set as Wallpaper Pair” or customise the lock screen only.
    4. Check that clock style, widgets and notifications don't overlap the paper. If they do, adjust the paper position in step 3 and export again.
    Android
    1. Download the PNG or tap Share / Save to Photos.
    2. Open it in Photos/Gallery → ⋮ → Use as / Set as wallpaper → Lock screen. Labels vary by manufacturer.
    3. Check the clock style and any lock-screen widgets against the paper.
    Mac
    1. Choose a computer preset in step 3 that matches your display resolution.
    2. System Settings → Wallpaper → Add Photo… and select the PNG. On recent macOS versions the lock screen uses the desktop wallpaper.
    Windows
    1. Settings → Personalization → Lock screen → Personalize your lock screen → Picture → Browse photos.
    2. The Windows clock sits at the lower left; keep the paper clear of it.
